# Лабораторная работа №2. Сайт кампейна "Аметистовый дозор"

Многостраничный сайт в поддержку настольной ролевой кампании «Аметистовый
дозор» (D&D 5e, аванпост «Падший дом»). Сайт выполнен на чистых HTML5 и CSS3:
JavaScript, Bootstrap и другие библиотеки не используются - вся интерактивность
(раскрывающиеся досье персонажей, улучшения построек, сворачиваемая сводка)
построена на стандартных элементах `details`/`summary` и свойствах CSS.

## Структура проекта

```
lab2/
├── index.html        - главная: о кампании, ссылки, статистика
├── settlement.html   - поселение «Падший дом»: постройки и параметры лагеря
├── characters.html   - дозорные: раскрывающиеся досье участников
├── chronicle.html    - хроника кампании (каркас раздела)
├── lore.html         - лор мира (каркас раздела)
├── css/
│   └── styles.css    - единый внешний файл стилей для всех страниц
└── img/              - иллюстрации (JPEG)
```

## Страницы сайта

| Файл | Раздел | Содержимое |
|------|--------|------------|
| `index.html` | Главная | Сводка кампании: мастер, система, сеттинг, длительность, дата старта; эмблема с обтеканием текстом; полезные ссылки сообщества; четыре плитки статистики |
| `settlement.html` | Поселение | Аванпост «Падший дом»: сворачиваемая сводка вкладов построек, 12 параметров лагеря (нулевые значения приглушены), карточки построек «Бар Тёплого ветра» и «Система укреплений» - стоимость, требования, таблицы эффектов, улучшения |
| `characters.html` | Дозорные | Досье участников в виде раскрывающихся карточек: портрет, имя и статус готовности на «лицевой» стороне; внутри - внешность, дополнительные сведения, достижения, предыстория, цитата героя |
| `chronicle.html` | Хроника | Каркас раздела: общая шапка и навигация, наполнение - в планах |
| `lore.html` | Лор | Каркас раздела: общая шапка и навигация, наполнение - в планах |

## Решения и приёмы

### Селекторы (7 видов)

| Вид | Примеры из `styles.css` |
|-----|-------------------------|
| По тегу | `h1, h2, h3, h4`, `body`, `figure img`, `figcaption` |
| По классу | `.card`, `.char-face`, `.status-signed` |
| По идентификатору | `#deekonus` - отступ прокрутки `scroll-margin-top` для прямой ссылки на досье |
| Потомковый (контекстный) | `.building-meta .item`, `.card.building figure` |
| Атрибутный | `.upgrade[data-status="built"]`, `.char-card details[open]` |
| Псевдокласс | `:hover`, `:not(:last-child)` |
| Псевдоэлемент | `::after` - стрелка раскрывающейся карточки и разделитель «·» в мета-строках |

### Интерактивность без JavaScript

- **Досье персонажей**: `summary.char-face` показывает портрет, имя и статус
  готовности; при раскрытии селектор `details[open]` поворачивает стрелку
  `::after` на 90 градусов.
- **Улучшения построек** - сворачиваемые блоки `.upgrade`; построенные
  (`data-status="built"`) подсвечены золотым, проекты - приглушены.
- **Сводка по постройкам** сворачивается в одну строку и разворачивается
  перед таблицей вкладов.
- Штатное поведение `details` даёт управление с клавиатуры и поддержку
  скринридеров без единой строки скриптов.

### Компоновка: Flexbox, Grid и обтекание

- Flexbox: карточка постройки (картинка рядом с текстом), "лицо" карточки
  персонажа, мета-строки, навигация.
- Grid: блок статистики на главной - `grid-template-columns: repeat(4, 1fr)`.
- Обтекание (`float`): эмблема на главной - `figure.align-right`; в стилях
  предусмотрен и зеркальный `.align-left`.

### Адаптивность и доступность

- `@media (max-width: 720px)`: навигация переносится по центру, обтекание
  картинок отменяется.
- `@media (max-width: 560px)`: карточки построек складываются в колонку.
- `@media (prefers-reduced-motion: reduce)`: переходы, подъём карточек и
  поворот стрелки отключаются.
- Скрытые подписи таблиц (`caption.sr-only`), `aria-current="page"` у текущего
  пункта меню, `alt` у всех изображений, `rel="noopener"` у внешних ссылок.

### Единицы измерения и цвет

- Единицы: `px` (основная типографика), `%` (ширины), `rem`/`em` (размеры
  относительно корня и родителя), `ch` (длина строки досье - `75ch`), `vh`
  (скругление «капсул» - `100vh`), `deg` (поворот стрелки).
- Цвет: палитра задана в `rgb()`, тени и свечение - в `rgba()`; наследование
  через CSS-переменные `var(--…)`.

## Как открыть

1. Распаковать архив или склонировать репозиторий.
2. Открыть `index.html` в любом браузере - сайт полностью работает локально,
   сборка и сервер не требуются.
